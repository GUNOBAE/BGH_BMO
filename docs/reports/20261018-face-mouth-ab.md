# 입 움직임 A/B 실험 결과

2026-10-18 · 상태: **비교 도구 구현 / 합성 인터페이스 검사 통과 / 실제 v3 그림·Pi·사용자 체감 미검증**

이번 보고서는 개발 결과 공유용이다. README·방문자용 작동 설명을 변경하지 않는다. Pi에 접속하거나 기존 BMO 프로그램을 수정·배포한 작업이 아니다.

## 사용자 피드백을 반영한 범위

기존 얼굴 디자인과 눈의 부드러운 움직임을 유지한다. 입이 몇 가지 포즈 사이를 이동한 뒤 잠깐 정지하는 리듬을 줄이는 것이 목표다. 전체 FPS를 낮추거나 모든 입 모양에 동일한 Hold를 추가하는 방식은 사용하지 않았다.

표정·연기 36종(울음 6종 포함), 공통 입 약 10종, 별도 효과는 확장 후보 범위다. 원작에서 36종을 모두 확인했거나 구현한 것으로 표시하지 않는다.

## 작성한 검토용 산출물

ChatGPT 대화 첨부로 별도의 `BMO_Mouth_AB_Lab.html`과 `BMO_Mouth_AB_Review_Kit.zip`을 제공했다. **이 커밋에는 아래 비교 도구 코드나 원본 그림이 포함되지 않으며, 개발 보고서만 추가했다.** 아직 GitHub에서 비교 도구를 내려받아 실행하는 상태가 아니다.

비교 도구는 사용자가 이미 가진 `BMO_Face_v3_Smooth_Voice.html`을 로컬 파일 선택으로 읽는다. 그 원본의 스크립트·도형을 브라우저 메모리의 제한된 프레임에서 사용한다. 새로운 BMO 얼굴을 생성하거나 원본 파일을 덮어쓰지 않는다.

- A: 원본 Smooth 렌더 경로.
- B: 원본 Speaking 포즈 시퀀스와 전체 주기를 사용하고, 입·치아·혀의 시간 경로만 다르게 계산.
- B의 눈·눈꺼풀·기타 얼굴 데이터는 같은 시점 A의 값과 동일하게 공유한다. 입 이외의 요소를 새 타이밍으로 보간하지 않는다.
- 인접한 입 목표의 영향을 시간상 겹치는 정규화 가중치로 합성한다. 커널은 컴팩트 cubic B-spline 형태이며, 좌표의 직접 cubic 보간 대신 비음수 가중합을 사용한다.
- 특정 포즈마다 정지하도록 강제하지 않는다. 반대로 말의 쉼이나 닫힘이 불필요하다는 뜻은 아니다.
- 대기·행복·슬픔에서는 변경을 우회하고 두 화면이 같은 상태를 표시한다. 일시정지와 연결 폭 조절을 제공한다.
- 마이크·오디오·네트워크 연결을 사용하지 않는 무음 비교용이다. 고정된 원본 포즈 시퀀스를 입력으로 사용하므로 실제 발화·발음·동시조음이 검증된 립싱크라고 부르지 않는다.

이 방법은 경로 비교의 한 후보다. 지나친 평균화로 입 모양의 구분이 약해질 수 있으며, 원작 같은 인상이나 자연스러움은 실제 원본으로 비교하기 전 확정할 수 없다. 강제 Hold를 없앤 것만으로 원작 연기가 재현됐다고 주장하지 않는다.

## 실행한 검사

이번 작업 환경에서 새 순수 JS 로직을 Node로 검사했다. **12개 검사 통과, 실패 0, skip 0.** 검사 항목은 커널 연결, 정규화·비음수 가중치, 루프 경계와 미분 연결, 프레임률과 무관한 시간 샘플링, 단일 포즈, 입력 불변성, 비입 요소 보존, 좌표 범위, 잘못된 입력·토폴로지 거부, 인접 목표 겹침, 반복 호출의 무상태성이다.

Chromium에서 합성 인터페이스 fixture로 **8개 항목을 확인**했다: 비입 데이터 동일, 일시정지, 비말하기 우회, 연결 폭 변경, 800×480 뷰포트 배치, CSP 네트워크 차단, 런타임 예외 없음, 호환되지 않는 원본 거부.

**중요한 검증 한계:**

- 원본 v3 전체 바이트의 작업 환경 복사가 허용되지 않았다. 읽을 수 있는 원본 인터페이스와 대조했고, 브라우저 실행은 작은 합성 fixture로 했다. 사용자 원본 그림으로 성공적으로 실행했다고 표현하지 않는다.
- 관리 환경에서 file URL 이동이 차단돼 브라우저 검사는 메모리 문서로 수행했다. 일반 PC/Pi에서 로컬 HTML을 실제로 여는 경로와 동일한 검증은 아니다.
- 검사 준비 중 CSP와 충돌한 동적 대기는 DOM 조회로 대체했다. 합성 fixture의 첫 프레임 음수 dt 오류를 수정했다. 비교 도구의 CSP를 느슨하게 하지는 않았다.
- 기존 BGH_BMO의 177개 검사를 다시 실행하지 않았다. Pi 화면·성능·발열·음성·립싱크·모터를 검사하지 않았다.
- 실제 문장 cue에 맞춘 닫힘과 쉼, 감정 유지 음성 연결, 울음 효과와 36종 새 도형은 이번에 구현하지 않았다.
