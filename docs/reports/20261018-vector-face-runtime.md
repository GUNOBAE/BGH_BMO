## 기존 비교본과의 차이

이전 `BMO_Face_Synced_Cels.html`은 검토한 녹화에서 추출한 70개 래스터 얼굴을 원본 영상 시계에 맞춰 재생했다. 새 `BMO_Vector_Face_Lab.html`은 **SVG 경로로 그린 입 11종·눈 7쌍을 선택하는 재사용 렌더러**다. 비디오 요소와 영상 재생 시계가 없다. 원본 박자는 별도 JSON 시간표로 선택적으로 재현한다.

눈 7쌍은 기본 눈과 세로 형태 변화·깜빡임 단계이며, 감정 7종이 아니다. 사용자가 기존 래스터 비교본을 좋아한 사실을 새 벡터의 승인이나 전체 제품 승인으로 승격하지 않았다.

## 구현한 것

- 기존 승인 기준의 원본 셀에서 공간적 경계 추출·채색 영역 정리를 수행했다. 스튜디오의 고해상도 벡터 원본을 복구한 것은 아니다.
- 눈·입의 비율은 해당 소스 기준이다. 소스 구도 차이는 평행 이동·회전·균일 배율로 정규화하고 가로/세로를 따로 늘리지 않았다.
- 입 외곽, 녹색 내부, 혀, 흰 치아를 같은 포즈의 불투명 영역으로 선택한다. 치아마다 외곽선을 중복으로 그리지 않고 한 경계를 유지한다. 시간상 좌표·색·투명도 평균, crossfade, 강제 부드러운 모핑은 없다.
- 눈/입 독립 선택과 한 keyframe의 원자적 동시 표시, 일시정지·탐색·반복·속도·초기화, SVG/조합 JSON 저장을 구현했다.
- 원작 박자(약 2.33초/25개 변환 keyframe), 관찰한 깜빡임 단계 재사용, 별도의 합성 제어 시간표를 제공한다. 합성 시험은 원작 연기나 발음 동기화라고 표시하지 않는다.
- 새 시간표 JSON을 읽고 알려진 도형 ID로 재생한다. 같은 음성의 시간표를 갖고 있는 경우에만 사용자가 선택한 로컬 음성의 currentTime을 시계로 사용할 수 있다. 오디오 선택만으로 재생되지 않는다.
- `window.BMOFace`의 `setPose`, `loadTimeline`, `play`, `pause`, `seek`, `reset`, `snapshot`, `exportSVG`를 준비했다. 네트워크 API나 원격 제어 수신기는 아니다.
- 메인 표시부는 SVG path만 사용한다. 원본과 비교 버튼에서만 별도 참고 PNG를 정지 화면으로 표시한다. 패키지에 원작 MP4나 오디오는 넣지 않았다.

## 오류·수정과 검증 경계

초기 색상 분류에서 압축 잡음이 지저분한 벡터 경계로 남아 연결 영역과 공간 경계 처리로 수정했다. 스크립트의 이름 충돌, 검사 selector가 SVG 데이터 속성까지 버튼으로 세던 문제, 자동 대기 함수의 CSP 충돌을 수정했다. CSP를 완화하지 않았다.

앱에서는 늦은 audio.play() 완료가 reset 뒤 실행을 재개할 수 있는 경로를 세대 번호로 무효화했다. 작은 화면의 max-height가 얼굴 전용 보기를 제한하는 CSS도 수정하고 다시 검사했다.

**관리형 Chromium에서 file:// 직접 이동은 정책으로 차단되었다.** 동일한 HTML을 메모리 문서로 읽어 검사했다. 정책을 변경/우회하지 않았으며, Windows 더블클릭 경로나 실제 Pi의 브라우저 검증은 아니다. Chromium 버전은 144.0.7559.96이다.

음성 검사는 생성한 무음 WAV로 상태와 시계만 시험했다. 실제 발화/발음 정확도·음색·립싱크 품질을 검사한 것이 아니다. 기존 BGH_BMO의 177개 검사를 다시 실행하지 않았으며 Pi의 GPU/CPU·발열·실물 화면·스피커·RP2040·팔도 검사하지 않았다.

## 남아 있는 범위

작은 원본 녹화의 윤곽·선 두께·팔레트는 정리 과정의 근사이며 새 벡터에 대한 시각 검수가 필요하다. 대표 도형을 재사용하므로 원작 시간표 모드도 70개의 모든 픽셀과 동일하지 않다. 원본에 없는 울음/분노 등 36종을 생성한 것이 아니다.

새 음성에서 발음별 시점을 자동 생성하는 단계, 감정별 원작 도형·눈물/균열, BGH_BMO 백엔드 연결, Pi 배포는 아직 없다. 이번 작업 뒤 별도 자율 개발이나 하드웨어 실행을 예약하지 않았다.
