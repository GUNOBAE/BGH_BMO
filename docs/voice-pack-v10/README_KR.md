## 이전 문서에서 갱신되는 부분

음성 ZIP은 이미 전달한 v10 그대로 고정하고 새 이름으로 재포장하지 않는다. ZIP 안 `HANDOFF_KR.md`의 개발 상태는 당시 `3ebe0fb…`를 기준으로 작성된 과거 기록이다. **본 인계는 이후 확인한 `91665e4dd19229d6144ff04d4a398b0181a98270` 기준의 보충 문서**다.

현재 코드에는 v8 음성팩 import/승인/재생과 Master Volume이 이미 있다. 다시 만들지 않는다. 다만 실제 v10의 `entries/spoken_text/file/requested_model` 형식, 비언어 클립, 새 이벤트는 그대로 들어가지 않는다. 추가된 wake WAV는 이제 파일이 존재하며, 남은 것은 검증된 등록·승인·연결이다. 새 OrganizedVoicePack의 PCM 한도는 30초라 C09/C12가 구 bank의 10초 제한을 넘는다는 이유만으로 새 경로까지 불가능하다고 판단하지 않는다.
