## 프로젝트 개요

작은 소품보다 **실제로 곁에 두고 사용할 수 있는 큰 BMO**를 만들고 싶었습니다. 그래서 7인치 터치 디스플레이를 기준으로 본체를 원작 모델 대비 약 **135%** 크기로 설계했습니다.

[brenpoly의 Be More Agent](https://github.com/brenpoly/be-more-agent)와 [BMO 외형 OBJ 모델](https://github.com/brenpoly/be-more-agent/releases/tag/v1.0-enclosure)을 참고했습니다. 기구 모델은 원본 메시 파일을 그대로 확대하거나 편집한 것이 아니라, 형상을 보면서 **Fusion 360에서 솔리드로 직접 다시 그렸습니다.**

화면, 물리 버튼, 팔, 카메라 및 오디오를 하나의 BMO에 통합하는 것이 목표입니다. 하드웨어가 완성되면 음성 대화 기능을 개발하고, 이후 내부 SSD를 활용한 개인 서버로 확장할 계획입니다.

## 기구 설계

7인치 화면에 맞춰 본체 비율과 화면 장착부를 설계했습니다. 내부에는 Raspberry Pi, 전원부, 맞춤형 PCB, 스피커 및 배선이 들어갈 공간을 구성했습니다.

**Fusion 360 모델링과 주요 부품 출력은 완료**했습니다. 7인치 화면은 실제로 장착해 작동을 확인했습니다. 팔다리는 최종 조립 과정에서 일부 치수를 더 수정할 수 있습니다.

## 하드웨어

Raspberry Pi 5 8GB가 메인 컴퓨터입니다. 화면·카메라·오디오와 상위 소프트웨어를 담당하고, 별도의 RP2040-Zero PCB가 버튼·IMU·서보 제어를 담당하도록 구성했습니다.

| 기능 | 부품 | 현재 상태 |
|---|---|---|
| 메인 컴퓨터 | Raspberry Pi 5 8GB | 사용 |
| 화면 | 7인치 DSI 터치 디스플레이 | 작동 확인 |
| 저장 장치 | SSD | 장착 완료 |
| 전원 | Geekworm X1203 UPS, X12-A1 배터리 보드, 18650 배터리 | 전체 통합 테스트 예정 |
| 음성 입력 | USB 마이크 | 전체 통합 테스트 예정 |
| 음성 출력 | MAX98357A 앰프, 스피커 | 전체 통합 테스트 예정 |
| 영상 | Raspberry Pi Camera Module 3 Wide | 전체 통합 테스트 예정 |
| 팔 동작 | 양팔 서보 | PCB 연결 및 동작 테스트 예정 |
| 냉각 | Raspberry Pi Active Cooler, 본체 냉각팬 | 최종 구성 테스트 예정 |

이 표의 **작동 확인**과 **테스트 예정**은 구분해서 갱신합니다. 구매하거나 장착했다는 사실만으로 전체 시스템 검증을 완료한 것으로 표시하지 않습니다.

## 맞춤형 PCB

전면 버튼, IMU 및 양팔 서보의 입출력을 처리하기 위해 **RP2040-Zero 기반 PCB**를 KiCad에서 설계했습니다. Raspberry Pi와 RP2040-Zero는 USB로 연결할 계획이며, 서보 전원은 RP2040 전원과 분리해 외부에서 공급하도록 설계했습니다.

| 대상 | 구성 |
|---|---|
| 버튼 | 방향 버튼 4개, 기능 버튼 3개 |
| IMU | MPU6050 |
| 서보 출력 | 오른팔 1개, 왼팔 1개 |
| 컨트롤러 | RP2040-Zero |

PCBWay에 PCB 제조와 **SMD 부품 실장**을 의뢰했습니다. MPU6050, 저항 및 커패시터 등 SMD 부품은 업체 실장 대상입니다. RP2040-Zero 모듈, 푸시 버튼, 서보 커넥터 등 관통홀 부품은 PCB를 받은 후 직접 납땜할 예정입니다.

현재는 **설계·발주가 완료된 상태**이며, PCB의 전원·통신·입출력 기능은 아직 실물 테스트 전입니다.

## 소프트웨어

### RP2040 펌웨어

PCB 수령 및 하드웨어 테스트 후 버튼 입력, MPU6050 데이터 읽기, 양팔 서보 제어와 Raspberry Pi 간 통신을 구현할 예정입니다.

### Raspberry Pi 및 AI

Raspberry Pi에서 화면, 음성 입출력 및 하드웨어 연동을 처리할 계획입니다. 대화 기능은 **음성 인식 → GPT API → 음성 합성** 흐름으로 개발할 예정입니다. 이후 화면 표현, 팔 동작 및 카메라 입력을 연결합니다.

로컬 AI의 **구동 시험은 완료**했지만, 현재 계획한 GPT API 기반 소프트웨어는 **아직 구현 전**입니다. 개인 웹 서버 역시 후속 개발 단계입니다.

| 화면 | 7인치 DSI 터치 디스플레이 | 1 | 정산 예정 |

| **합계** | **BMO 한 대의 실제 사용 비용** | | **정산 예정** |

현재 확인한 **AliExpress 주문 13건의 결제 합계는 174,120원**입니다. 여분과 비교·시험용 부품이 포함되어 있고 다른 구매처의 부품은 빠져 있으므로, 이는 **최종 제작비가 아닌 구매 내역 일부의 합계**입니다.

PCB 제조·SMT 실장·배송비는 PCBWay의 협찬을 받았습니다. 부품 사용 여부가 확정되면 **전체 구매액 / 실제 사용 비용 / 협찬 금액 / 직접 지출액**을 구분해 갱신하겠습니다.

## Troubleshooting & Design Changes

제작 중 **직접 확인한 문제와 설계 변경**을 이곳에 기록합니다. 완료된 하드웨어나 소프트웨어의 설명에는 변경 이력을 반복하지 않습니다.

### 메시 모델을 솔리드로 재설계

원작 OBJ의 외형을 참고하면서 화면 장착부와 내부 조립 구조를 수정하려 했습니다. 메시 형상으로 필요한 치수와 결합부를 관리하기 어려워, Fusion 360에서 솔리드 모델을 직접 다시 설계했습니다.

### 로컬 AI 시험 후 방향 변경

Raspberry Pi AI 가속기를 이용해 로컬 AI를 실제로 구동했습니다. 그러나 시험한 대화 성능이 목표에 맞지 않아 가속기를 제거하고 SSD를 장착했습니다. 대화 소프트웨어는 GPT API 방식으로 새로 개발할 계획이며, **변경 후 방식의 동작은 아직 검증되지 않았습니다.**
